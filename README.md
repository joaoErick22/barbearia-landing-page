# ✂️ Barbearia - Landing Page

Landing page responsiva para barbearia, focada em visual profissional e conversão de clientes.

### 🛠️ Tecnologias
`HTML` `CSS` `JavaScript`

### ✨ Funcionalidades
- Página inicial com apresentação da barbearia
- Seção de serviços e preços
- Seção de agendamento
- Layout responsivo para celular e desktop

### ▶️ Como rodar
1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
